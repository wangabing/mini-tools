# 小站工具实现与验收

首页 `/` 列出 79 个工具入口，对应 71 条工具路径和 8 个单位换算预选状态。全部工具链接和搜索结果走站内路径。支持和隐私页面分别在 `/donate/` 和 `/privacy/`。旧计算器页面归档在 `app/_liheng/`。

目录数据在 `src/data/betool.ts`，工具组件在 `components/betool/`。站名和口号在 `src/config/brand.ts`，百灵鸟图标在 `app/icon.png`，既显示在页眉，也供浏览器标签页使用。

运行 `npm ci` 和 `npm run dev` 可启动本地开发预览。`npm run build` 导出到 `out/`。GitHub Pages 继续使用已有域名和部署流程。启动开发或构建时会把安装包中的 PDF.js worker、字符映射、标准字体和 WebAssembly 复制到站内。

工具在浏览器内处理文件和数据，无应用后端、数据库或第三方 API 凭据。M3U8 示例由本站提供，播放自填地址需要流源可访问，并遵守其跨域设置。部分计时统计和设置可存到当前浏览器。

工具目录和交互以公开的 [BeTool 工具页](https://www.betool.cn/) 为参考。工具图标在 `public/betool/` 保留原文件名。支持页使用自己的品牌，保留待配置状态。

## 文件处理

PDF 合并时，浏览器读取用户选中的 `File`，调用 `arrayBuffer()` 获取文件字节。站内打包的 `pdf-lib` 按当前文件列表顺序载入原件，将页面逐个复制到新 PDF，并生成 `merged.pdf`。页面资源和内容一起复制。下载通过浏览器内的 `Blob` 和临时地址触发，文件处理全过程在本机进行。 [合并实现](../components/betool/media/pdfBrowser.ts) · [下载实现](../components/betool/media/mediaBrowser.ts)

PDF.js 用于页面预览和图像渲染。PDF 转图片、图像化压缩所需的 worker、字符映射、标准字体和 WebAssembly 由本站提供。合并直接复制 PDF 页面，处理过程会占用设备内存。当前没有加密文件解锁流程。 [静态资源脚本](../scripts/sync-pdfjs-assets.mjs)

## 验收记录

首轮验收使用正式域名配置生成静态产物，浏览器遍历 79 个工具入口及两个信息页。HTTP 均返回 200，390 px 宽度下没有横向溢出。ESLint、TypeScript 和 93 项 Vitest 测试通过。此记录针对本地静态产物，线上版本以 Pages 发布验收为准。 [发布验收](deployment.md)

| 范围 | 验证的输出与行为 |
| --- | --- |
| PDF | 三份文件重排后合并，重新解析下载文件并核对页数、页尺寸顺序和内容流。拆分、提取、旋转、压缩、图片转 PDF、PDF 转图片均读取或解包了下载结果。 |
| 图片与二维码 | 校验裁剪、旋转、取色、水印、压缩、文字图和差分预览。解码下载的普通二维码和组合收款二维码，核对原始内容。 |
| 开发运维与文本 | 断言编码、格式化、哈希、进制、统计和文本转换等核心输出。浏览器验证正则 worker 匹配和 SHA-256 已知值。 |
| 教育、图表与随机 | 覆盖八个单位换算状态、摩斯电码、进制和 ASCII。校验六种随机流程、CSV/XLS/XLSX 样例、图表 PNG/JPEG 和词云文件输出。 |
| 日常工具 | 断言人民币金额往返、计算优先级与小数、色值与表情剪贴板、番茄时钟、反应测试、猜拳统计、弹幕播放和站内 HLS 解码。 |

## 与参考站的差异

- 首页延续顶部搜索、分类侧栏、工具卡片和响应式列数。页眉及浏览器图标采用小站工具品牌，侧栏提供站内支持页和隐私说明。参考站的友情链接、赞助榜和收款资料已移除。
- 代码类工具使用普通文本输入区。文本对比通过按钮触发。富文本工具栏更精简，文字转图使用全文样式。图表、图片编辑与随机工具的选项和交互也有差异。
- 组合收款码已核对两侧二维码载荷，真实支付应用扫码尚未验证。超大 PDF、书签和可编辑表单尚无完整验收记录。新生成的 PDF 需要重新签署才能具备有效数字签名。

后续验证可以按 [迭代清单](betool-roadmap.md) 依次记录。
