## 3. 平台费率精确化所需材料

当前最需要真实材料的是淘宝、天猫、京东、拼多多、抖音和快手。这六个平台覆盖货架、内容、分销和履约等主要成本类型。

每个平台建议提供一份脱敏材料：

- 店铺主体类型和店铺模式，例如个人店、企业店、旗舰店或 POP。
- 实际经营类目和一个典型商品价格区间。
- 商家后台当前费用页面、官方规则链接或合同费用页截图。
- 每项费用的名称、费率或固定金额、计费基数、生效时间和是否含税。
- 退款、部分退款、取消订单时，各项费用是否退回。
- 达人/分销佣金、投流、运费险、物流和活动让利是否单独发生。
- 保证金、年费或软件费的金额，以及预计月订单量，便于按订单摊销。

不需要提供平台密码、短信验证码、Cookie、密钥或完整未脱敏合同。截图可遮盖店铺名、账号、联系人、订单号和金额等敏感信息，只保留规则口径。

## 6. 计算内容采集与行业分析前的必要决定

当前产品明确承诺不上传、保存或分析计算内容。任何采集功能上线前，必须先完成以下决定和改造，不能静默开启：

- 明确采集目的、字段清单和用户能获得的直接价值。
- 设计独立、主动的同意动作；未同意时保持完全本地计算。
- 更新隐私政策，说明保存时间、使用范围、撤回和删除方式。
- 确定数据存储地区、访问权限、备份、加密和泄露响应责任人。
- 确定单机持久化 SQLite 或远程 SQLite 兼容服务，不能使用会丢失数据的临时磁盘。
- 服务器重新校验输入并重算结果，不直接信任浏览器提交的利润结果。
- 处理机器人、重复提交、默认示例、极端值和过小样本。
- 对外分析只能表述为“工具用户样本”，不能代表整个行业。

开始这一阶段时，至少需要你确认：采集目的、部署方案、保留期限、隐私联系人和首批分析指标。
