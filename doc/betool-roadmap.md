# 小站工具迭代清单

当前基线包含 71 条工具路径、79 个目录入口和两个信息页。优先提高高频工具的可靠性，并验证正式域名上的发布产物。已验证结果和参考站差异见 [实现与验收](betool-reference.md)。

## 下一轮

| 顺序 | 待办 | 完成依据 |
| --- | --- | --- |
| 1 | 补测 PDF 合并和下载 | 扩展混合横竖页、扫描件、中文字体和大文件样例。重新打开输出检查页数、顺序及可见内容。记录处理耗时，并核对损坏和加密文件的提示。 |
| 2 | 核对 PDF 的文档级内容 | 用带书签、表单和签名的文件检查生成结果，记录哪些内容可以保留以及对应提示。 |
| 3 | 验收正式地址 | 获取实际部署的提交和 URL，检查 HTTPS、直接访问子路由、搜索、PDF 下载和站内视频示例。 [部署验收](deployment.md) |

## 每轮记录

记录日期、工具路径、修改点、输入或样例来源、预期与实际输出、浏览器和构建版本。对文件工具保留可复用的样例或生成方式。完成后更新 [验收记录](betool-reference.md)，剩余差异继续留在对应待办中。
