# 电商利润计算器用户操作文档

> 版本：1.5
> 更新日期：2026-10-04

## 1. 先选择适合的平台

不确定在哪个平台起步时，打开“平台对比”。先按低门槛试水、内容带货、品牌经营、本地即时零售或批发/B2B 筛选，再保留最多三个候选。

对比时优先看自己的现有能力：稳定货源、内容生产、品牌资质、本地门店和企业销售能力。近期活动与权益必须通过页面提供的官方入口再次确认。

## 2. 快速计算

1. 选择销售平台。没有匹配平台时保留“通用电商”。
2. 选择商品分类。平台没有专属分类费率时会使用平台通用参考。
3. 当前国内版统一使用人民币 CNY，不进行汇率换算。
4. 填写商品售价、商品成本、物流或履约成本和单笔广告成本。
5. 右侧或下方结果会即时更新，不需要点击提交。

## 3. 高级设置

高级设置默认是“快速估算”。它适合刚开始核价或暂时只有汇总费率的场景，可以补充：

展开“高级设置”可以补充：

- 买家支付运费和订单折扣
- 包装与其他单笔成本
- 平台佣金、支付费率和固定支付费
- 税费、退款损失预留
- 目标利润率和月订单量

国内平台自动填入的费率只是参考值。页面显示“待核对”时，0 费率不代表免佣；请展开高级设置，使用商家后台或合同中的实际费率覆盖。修改后页面会显示“已手动调整”。

完成填写后，勾选“我已按后台或合同核对当前费用”。勾选只表示你确认了当前输入，不代表平台或本站对费率进行了官方认证。切换平台、分类或再次修改费用后，确认状态会自动取消。

## 4. 专业核算

需要对照平台账单、达人订单或月度经营成本时，在高级设置中选择“专业核算”。核心售价、商品成本、物流和广告输入会保留。

1. 在“收入与订单成本”填写商家承担优惠、平台补贴、保险和其他订单成本。
2. 选择成交渠道，并分别填写平台、支付和税费的费率、固定费及计费基数。
3. 达人或分销成交时补充佣金；切回自然或广告成交后，佣金输入不会参与计算。
4. 在“售后风险”填写退货率、逆向运费、处理成本、货值损失和交易费不退比例。
5. 在“月度规划”填写平台/软件月费、运营固定月成本和预计订单量。

三个计费基数分别是：优惠后的商品金额、包含买家运费的买家实付、再加平台补贴后的商家结算。请按后台账单或合同选择，不要仅凭字段名称猜测。

淘宝、天猫、京东、拼多多、抖音和快手会显示平台常用字段名称与核对清单，但不会自动填入未经核验的数字费率。模板显示“待复核”时仍可使用，定价前应重新核对官方入口。

## 5. 结果说明

- 订单贡献利润：一笔订单收入扣除当前已填写成本后的金额，不等同于会计净利润。
- 贡献利润率：订单贡献利润占订单收入的比例。
- 订单成本回报：订单贡献利润相对于当前订单总成本的比例。
- 预计月贡献：快速模式为订单贡献利润乘以订单量；专业模式已扣除填写的月度固定成本一次。
- 保本售价：在当前成本和费率下利润为 0 的最低估算售价。
- 目标售价：达到高级设置中目标利润率所需的估算售价。
- 最大广告成本：其他条件不变时，单笔订单能够承担的广告上限。
- 盈亏平衡 ROAS：广告回报低于该数值时，订单预计开始亏损。

贡献刻度将成本与剩余利润放在同一条收入尺度上。成本构成条展示商品、履约、广告、平台支付、风险和其他成本的比例。

专业结果还会单独显示商家结算收入、交易费用、预期售后损失和单笔月费分摊。预期售后损失是“退货率 × 单次退货损失”，不是所有销售额都直接扣除同一比例。

“核算完整度”检查九类常见经营项目，并把当前为 0 的区域列为“建议确认”。0 元可能符合实际，例如自然流量订单可以没有广告成本；该提示不是报错，而是提醒你在作出定价或投流决策前主动核实。

## 6. 常见情况

### 结果显示亏损

检查商品成本、物流、广告和费率是否使用相同订单口径，再比较保本售价与当前售价。利润不会被工具强制显示为零。

### 无法计算目标售价

平台、支付、税费、退款与目标利润率合计过高，公式没有有效分母。降低目标利润率或核实费率。

专业模式还会在当前成本和费率结构无法达到目标时停止反推。如果填写了月度固定成本但月订单为 0，请先补充预计订单量；工具不会默默忽略月成本。

### 平台费与实际账单不同

平台预设没有覆盖全部分类、售价阶梯、订阅、履约和促销规则。打开高级设置，使用实际账单费率覆盖参考值。

### 为什么只能使用人民币

当前版本针对国内平台，统一使用人民币，避免只更换货币符号却没有换算金额造成误解。跨境平台、汇率日期、税费和海外仓将作为独立模式建设。

### 结果显示“费用待核对”

这表示平台的实际费率需要登录商家后台或查看合同，当前数字只是一份预览。展开高级设置填写真实费用，确认无遗漏后再勾选费用核对项。

## 8. 隐私保护

所有计算都在当前浏览器内完成。售价、成本、费率和利润结果不会上传、保存或用于分析；刷新或关闭页面后，本站无法找回这些内容。

网站当前没有账号、在线留言、访问统计或计算数据提交功能。联系邮件由你在自己的邮件应用中主动发送，不经过本站，也不会自动带上计算器里的任何经营数字。
