# 电商利润计算器用户操作文档

> 版本：1.3  
> 更新日期：2026-10-03

## 1. 先选择适合的平台

不确定在哪个平台起步时，打开“平台对比”。先按低门槛试水、内容带货、品牌经营、本地即时零售或批发/B2B 筛选，再保留最多三个候选。

对比时优先看自己的现有能力：稳定货源、内容生产、品牌资质、本地门店和企业销售能力。近期活动与权益必须通过页面提供的官方入口再次确认。

## 2. 快速计算

1. 选择销售平台。没有匹配平台时保留“通用电商”。
2. 选择商品分类。平台没有专属分类费率时会使用平台通用参考。
3. 选择币种。所有金额必须使用同一种币种，工具不会自动换汇。
4. 填写商品售价、商品成本、物流或履约成本和单笔广告成本。
5. 右侧或下方结果会即时更新，不需要点击提交。

## 3. 高级设置

展开“高级设置”可以补充：

- 买家支付运费和订单折扣
- 包装与其他单笔成本
- 平台佣金、支付费率和固定支付费
- 税费、退款损失预留
- 目标利润率和月订单量

国内平台自动填入的费率只是参考值。页面显示“待核对”时，0 费率不代表免佣；请展开高级设置，使用商家后台或合同中的实际费率覆盖。修改后页面会显示“已手动调整”。

## 4. 结果说明

- 单笔贡献利润：一笔订单收入扣除当前全部成本后的金额。
- 利润率：利润占订单收入的比例。
- ROI：利润相对于总成本的比例。
- 月利润：单笔利润乘以预计月订单量。
- 保本售价：在当前成本和费率下利润为 0 的最低估算售价。
- 目标售价：达到高级设置中目标利润率所需的估算售价。
- 最大广告成本：其他条件不变时，单笔订单能够承担的广告上限。
- 盈亏平衡 ROAS：广告回报低于该数值时，订单预计开始亏损。

贡献刻度将成本与剩余利润放在同一条收入尺度上。成本构成条展示商品、履约、广告、平台支付、风险和其他成本的比例。

## 5. 常见情况

### 结果显示亏损

检查商品成本、物流、广告和费率是否使用相同订单口径，再比较保本售价与当前售价。利润不会被工具强制显示为零。

### 无法计算目标售价

平台、支付、税费、退款与目标利润率合计过高，公式没有有效分母。降低目标利润率或核实费率。

### 平台费与实际账单不同

平台预设没有覆盖全部分类、售价阶梯、订阅、履约和促销规则。打开高级设置，使用实际账单费率覆盖参考值。

### 币种切换后数值没有换算

币种选择只改变金额格式，不进行汇率换算。切换币种后应同时输入该币种下的售价与成本。
